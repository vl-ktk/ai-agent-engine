# AI Agent Engine — единый план реализации

**Редакция 17.11.2026, утверждённое владельцем дробление:** неизменные **11 глобальных этапов**, теперь **169 прямых подпунктов** вместо 79. Единственный действующий план в `vl-ktk/ai-agent-engine`, ветка `main`. Прежняя редакция сохранена в GitHub history (commit `3b34e25780529e785c165318d46fbbe95b51de48`), но **не является вторым планом**.

**Зачем изменён размер:** каждый подпункт теперь отдельный законченный результат с конкретной проверкой. **За один заход:** весь один подпункт → тесты/живые проверки и разрешённая публикация → запись версии и отката → **один краткий отчёт** → пауза до явного «Давай дальше». Не вводить третью ступень номеров и не дробить отчёты на «часть готова, можно дальше?».

**Этап 4 принят 18.11.2026 в границах действующего Netcup VPS.** Подпункты 4.19–4.23 выполнены по задокументированным live/offline-проверкам; итоговый **4.24 [x]** — владелец принял удалённое управление, семь штатных локальных снимков, проверенное изолированное восстановление SQLite и отсутствие новых платных ресурсов в AI Agent Engine. Внешняя копия при полной утрате VPS **не доказана**; счета всех услуг Netcup **не проверялись** по прямому решению владельца, эти вопросы не выдаются за PASS. [Точная область приёмки](./infra/backup/STAGE4_24_VALIDATION.md), остальные факты — `HANDOFF.md`. **Этап 5 начат с 5.1 [x] по локальным API/юнит-тестам; следующий 5.2 [ ].** Посторонние модели и оборудование других проектов не входят в данный этап.

**Статусы:** [x] — действие и соответствующая проверка подтверждены в ранее принятом объёме либо фактическими live-логами; [ ] — не сделано/требует проверки/приёмки; `BLOCKED` — реальный стоп; `DEFERRED` — только согласованное с владельцем обоснованное исключение. Новая разбивка **не делает непройденные проверки успешными**. Ранние открытые подпункты 1–2 сохраняют открытый статус; работа над этапом 4 ведётся по прежнему явному приоритету владельца от 17.11.2026.

**Полномочия:** бесплатные штатные действия внутри порученного подпункта выполняются без повторных вопросов; нельзя самостоятельно создавать расходы, платные API, менять секреты/права, удалять рабочие данные или работать с чужой частью проекта. По каждому изменению перед выкладкой заново проверить `main` и текущую live-версию, сохранить rollback ID, провести тесты; при блокере остановиться именно на нём. В рамки AI Agent Engine входят оркестрация, разрешённые GPT/Claude-адаптеры, Netcup, хранилище, безопасность, MCP, QA, интерфейс и память. Дополнительное оборудование для запуска собственных моделей не является частью этого плана.
