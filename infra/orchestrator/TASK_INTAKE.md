# 5.1 — API приёма задач (локальный прототип)

**Статус:** проверяемая реализация первого подпункта этапа 5 AI Agent Engine.
Никаких моделей, платных API или новых VPS не требуется. Сервер Netcup здесь
не перенастраивается.

## HTTP-контракт

- `POST /v1/tasks`, `Content-Type: application/json` (допустим UTF-8 charset).
- Тело: **ровно три обязательных строковых поля**:
  - `project_id` — идентификатор проекта 1–128 символов:
    латинские буквы, цифры, `_`, `.`, `:`, `-`; первый символ — буква/цифра.
  - `title` — непустое название длиной до 1024 символов, без управляющих.
  - `prompt` — непустая постановка задачи до 32768 символов.
- Кодировка строго UTF-8; JSON-ключи не должны повторяться. Лишние поля и
  вложенные объекты вместо строк отклоняются. Размер запроса не более 49152
  байт. HTTP `Content-Length` обязателен.
- Успех: **`202`**, `{"status":"accepted_in_memory","receipt":1}`.
  `receipt` — **только локальный номер приёма в памяти процесса**,
  не стабильный `task_id`, не гарантия обработки или долговечного хранения.
  Тело задачи обратно клиенту не отправляется.

| HTTP-код | Причина |
| --- | --- |
| 400 | Некорректный JSON/UTF-8, нулевая длина, ошибочный Content-Length или неполное тело |
| 404 | Неизвестный путь |
| 405 | Неподдерживаемый метод |
| 411 | Отсутствует Content-Length |
| 413 | Тело больше установленного лимита |
| 415 | Content-Type не JSON |
| 422 | Недостающие, неизвестные или неправильные поля |
| 503 | Приёмник заполнен (по умолчанию максимум 128 задач) |

Ошибки возвращают только безопасный машинный код, не цитируют запрос,
промпт, секреты, URL или содержимое исключений. HTTP-запросы и их данные
не записываются в журнал.

## Локальный запуск (не на публичном VPS)

В явном порядке из checkout, без внешних библиотек:

```bash
python3 -m ai_agent_engine.task_api --port 8765
```

Слушатель жёстко ограничен `127.0.0.1`, доступ извне не открыт.
В отдельном терминале:

```bash
curl -i --request POST http://127.0.0.1:8765/v1/tasks \
  --header 'Content-Type: application/json' \
  --data '{"project_id":"project-a","title":"Пробная задача","prompt":"Подготовить план"}'
```

Реальная проверка HTTP производится автономными тестами без ручного запуска
службы:

```bash
python3 -m unittest tests.test_task_api -v
python3 -m unittest discover -s tests -q
```

## Принципиальные границы

1. Реализация `TaskInbox` держит ограниченное число объектов **только в RAM**.
   При завершении процесса данные исчезнут: **долговечная очередь — 5.5**.
2. Разрешения пользователя/исполнителя ещё не внедрены. Поэтому слушатель
   **не должен** попадать в публичную сеть или systemd production; позже
   потребуются аутентификация, права и лимиты.
3. Стабильные task/subtask/owner IDs относятся к **5.2**;
   зависимости/приоритеты — **5.3–5.4**; назначение и выполнение — последующие
   пункты. Получение `202` не означает, что модель начала работу.
4. Никакой работающей версии Netcup или рабочей SQLite эта реализация не
   изменяет. Для закрытия 5.1 достаточно юнит/HTTP-тестов и публикации кода
   в утверждённый GitHub `main`.
