## Проверено непосредственно на действующем VPS

1. Через независимую облачную сессию авторизованного Netcup SCP открыт
   VNC-терминал **уже арендованного** VPS; панель показывает `RUNNING`.
   Это доказывает возможность управления без подключения к локальному терминалу
   домашнего компьютера во время теста. Владелец отдельно сообщил, что домашний
   ПК в этот период **даже не включал**; отдельный физический тест не проводили.
2. `systemctl is-active ssh.service ae-controller.service ae-backup.timer
   ae-host-check.timer` → четыре строки `active`. При проверке не меняли
   службы/таймеры или релиз. Последний подтверждённый ранее контроллер
   `0.3.8a0`, release `85375103800845eeff696e53f510c66c428408ed`;
   этот SHA в рамках **самого 4.24 не считывался повторно**.
3. `ls -1 /var/backups/ai-agent-engine` → **7** локальных снимков. Последний
   `20261118T100456.636455Z-6da03b65`. Повторно запущено от `ae-runtime`
   `python3 /usr/local/libexec/ae-backup.py verify` →
   **`backup verify PASS bytes=53834 retained=7`**.
4. Создан отдельный приватный staging
   `/var/tmp/ae-restore-424.xgvgDHJz` (`0700 root:root`), рабочие каталоги не
   использовались. Из последнего снимка `cp --no-clobber` скопировал
   `engine.sqlite3`, `tar -xzf --no-same-owner` распаковал `files.tar.gz`.
   `cmp` исходной и восстановленной SQLite → без различий;
   `tar -dzf ... -C /var/tmp/ae-restore-424.*` → без различий;
   `python3 -m sqlite3 /var/tmp/ae-restore-424.*/engine.sqlite3
   "pragma integrity_check"` → **`('ok',)`**. `stat` подтвердил staging
   `0700 root:root`, БД `0600 root:root`.
5. Архив содержит только пустые `projects/`, `workspaces/`, `artifacts/`;
   **вложенных рабочих файлов в данном live-снимке нет**. Их восстановление
   отдельно проверялось синтетическим тестом 4.20, не в этом live-снимке.
6. В Netcup SCP раздел Servers показывает **1 из 1** доступный VPS
   (`VPS Lite 2 G12s`, RUNNING). SCP General/Account Settings не содержат
   договорного перечня услуг и счетов. **Новых VPS, платных функций,
   подписок или API при этой проверке не заказывали**. Это **не доказательство
   нулевых дополнительных списаний**.
